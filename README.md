# עדכון מדריכות — 19.09.2026

החבילה מיועדת להתקנה אחרי עדכוני התשתית, הייבוא והפרסום הקודמים של אזור המדריכות.

## סדר התקנה

1. העלי את כל הקבצים שבתיקייה זו לשורש הפרויקט, תוך שמירה על הנתיבים והחלפת הקבצים הקיימים.
2. המתיני לסיום הפריסה ב־Vercel.
3. ב־Supabase SQL Editor הריצי פעם אחת את:
   `supabase/migrations/017_educator_directory_refinement.sql`
4. בסיום תקין תופיע טבלה עם שלוש שורות של סטטוס אונליין:
   - `yes` — 14
   - `special` — 3
   - `no` — 7
5. בדקי את `/educators`, סינון לפי אזור, סינון אונליין, פרופיל מדריכה, הצגת טלפון ומעבר לוואטסאפ.

## מה נכלל

- החלפת שיוכי האזורים ותתי־האזורים של כל 24 המדריכות לפי המיפוי שאושר.
- שלושה מצבי קבלת אונליין: כן, במקרים מיוחדים, לא.
- תשתית לשם מותג ולמשפט מבדל; שדות חסרים אינם מוצגים.
- סינון קומפקטי לפי אזור/תת־אזור ואונליין.
- תוצאות לפי תת־אזור, סביבה מקומית ואזורים שכנים בעת היצע נמוך.
- כרטיס שלם לחיץ; מדריכה מושהית מואפרת ומסומנת „לא מקבלת קהל” אך נשארת נגישה.
- היררכיית מידע חדשה בפרופיל וקישור חזרה לכל המדריכות.
- מספר טלפון נשלף רק בלחיצה; כפתור WhatsApp עם הודעת פתיחה.
- ניקוי נתוני המקום הישנים של איילה והסימן השגוי אצל טל.
