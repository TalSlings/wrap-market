# עדכון כרטיסים ופרופילי מדריכות — 28.09.2026

עדכון עיצובי ותוכני שמטרתו להפוך את אזור המדריכות ממאגר פרטים להזמנה להיכרות ולפנייה.

## התקנה

להעלות את כל הקבצים תוך שמירה על הנתיבים ולהמתין לסיום הפריסה ב־Vercel:

- `app/educators/[id]/page.tsx`
- `app/globals.css`
- `components/EducatorBackLink.tsx` — קובץ חדש
- `components/EducatorCard.tsx`
- `lib/educators.ts`

אין צורך להריץ SQL.

## מה השתנה בכרטיסי המדריכות

- התמונה מוצגת כמלבן קטן בצד הכרטיס: גדולה מספיק לזיהוי, אך אינה משתלטת על הכרטיס ואינה נחתכת לעיגול.
- השם והמותג מופיעים ראשונים; אחריהם בלוק מסודר ואחיד של הכשרה ואזור.
- ההכשרה נשארת בכרטיס במלואה.
- המקצועות המשיקים והנוספים עברו לפרופיל המלא.
- נוספה הזמנה עדינה „להכיר את…” והכרטיס כולו נשאר לחיץ.
- אחרי המידע היבש מופיע אזור „כמה מילים ממני”, במשקל עדין ובגובה קבוע של עד שתי שורות. משפט ייעודי מקבל עדיפות; עד שייכתב, מוצג תקציר מסומן מתוך „עליי” או הגישה כדי שלא ייראה כקטע חסר הקשר.

## מה השתנה בפרופיל המלא

- תמונת פתיחה גדולה, שם, מותג, משפט מבדל ואזורים.
- אזור יצירת קשר בולט מיד אחרי הפתיחה וחזרה עליו בסוף העמוד.
- ההכשרה, המקצועות והפעילות ההתנדבותית מוצגים במלואם באזור מקצועי אחד.
- „עליי” והגישה להדרכה מוצגים כרצף קריא ואנושי, לא כאוסף שדות.
- הקישורים החיצוניים והמידע המעשי מופיעים בהמשך היררכי ברור.
- כפתור „חזרה לכל המדריכות” מופיע בראש ובסוף. כשהכניסה הייתה מרשימת המדריכות, החזרה שומרת את הסינון ואת מקום הגלילה.

## משפט פתיחה זמני

אם עדיין אין למדריכה משפט מבדל ייעודי, המערכת משתמשת זמנית בטקסט קיים שלה. בכרטיס הרשימה הוא מופיע תחת „כמה מילים ממני” ומוגבל לשתי שורות; בפרופיל המלא הוא משמש כפתיח. לאחר שהמדריכות יערכו את הפרופילים שלהן, `card_intro` ימשיך לקבל עדיפות.

## רשתות חברתיות

הקישורים לרשתות ולאתר מופיעים בפרופיל המלא מיד אחרי אזור הפנייה ולפני המידע המקצועי, כדי שיוכלו לשמש דרך מרכזית להכיר את המדריכה. קישור YouTube מזוהה ומוצג בשמו במקום תחת הכותרת הכללית „רשת חברתית נוספת”.
