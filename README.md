# עדכון תצוגת מדריכות במובייל — 19.09.2026

החבילה מותקנת אחרי `wrap-educators-directory-refinement-19-09-2026.zip`.

## התקנה

1. העלי את הקבצים לשורש הפרויקט תוך שמירה על הנתיבים והחלפת הקבצים הקיימים.
2. המתיני לסיום הפריסה ב־Vercel.
3. הריצי ב־Supabase SQL Editor את:
   `supabase/migrations/018_educator_profile_images_foundation.sql`

המיגרציה יוצרת תשתית בלבד לתמונות נוספות. היא מפעילה RLS, אינה מפרסמת תמונות ואינה משנה את התמונות הקיימות.

## מה השתנה

- בכרטיס המדריכה מוצג תת־אזור מדויק רק כשיש תת־אזור יחיד; במקרים האחרים המידע נדחס לאזורי־גג.
- נוסף סמל מיקום.
- מידע על קבלת אונליין הוסר מהכרטיסים ונשאר כסינון.
- ההכשרה מודגשת ומוצגת עם תווית.
- מוצגים מקצועות משיקים; כשאין כאלה מוצגים מקצועות נוספים.
- הטקסט והמרווחים בכרטיסים הוקטנו, במיוחד במובייל.
- בפרופיל המלא נוספו מסגרות והיררכיה ברורה יותר.
- קישורי הרשתות מוצגים ככפתורים, מיושרים לשמאל ועולים לפני המידע המקצועי במובייל.
- תשובות ריקות ותשובות כמו „לא”, „אין” ו„לא רלוונטי” אינן מוצגות.
- פירוט אזורי השירות המלא נשמר בתחתית הפרופיל בלבד.
- נוספה תשתית מאובטחת לתמונות נוספות, ללא החלטה על מיקום או צורת גלריה.
