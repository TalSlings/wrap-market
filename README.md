## התנהגות הסינון

- רכיב יחיד וסגור כברירת מחדל.
- כשהוא סגור הוא מציג את הבחירה הנוכחית.
- „מקבלת אונליין” מופיעה בראש התפריט בעיצוב מובחן.
- אחריה מופיעים אזורי־הגג.
- נגיעה באזור־גג פותחת את האפשרות „כל אזור…” ואת תתי־האזורים שלו.
- בחירה מסננת מיד; אין צ׳קבוקס ואין כפתור אישור.
- אפשר לבחור אפשרות אחת בלבד.
- „כל המדריכות” מנקה את הסינון.
- טעינה מוקדמת של עשרות קישורי הסינון כבויה כדי לא להוסיף עומס מיותר.
