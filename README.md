3. להמתין לסיום תקין של הפריסה ב־Vercel.
4. ב־Supabase SQL Editor להריץ פעם אחת את:

   `supabase/migrations/020_educator_photos.sql`

## מה כלול

- תמונה ראשית בכרטיס ובפרופיל המלא של 17 מדריכות.
- אופטימיזציית תמונות דרך Next.js כדי שכרטיסים בנייד לא יורידו את קובצי המקור הגדולים.
- תשתית לשתי תמונות אצל יעל גלובמן ושירן מאור. בשלב הזה הכרטיס והפרופיל מציגים את התמונה הראשית בלבד; התמונות הנוספות שמורות לשלב שבו נוסיף גלילה או גלריה.
