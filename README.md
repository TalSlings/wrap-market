# עדכון כרטיסי מדריכות, סינון ומדריכה נוספת — 19.09.2026

החבילה מותקנת אחרי עדכוני המדריכות הקודמים.

## התקנה

1. העלי את הקבצים לשורש הפרויקט, שמרי על הנתיבים והחליפי את הקבצים הקיימים.
2. המתיני לסיום הפריסה ב־Vercel.
3. הריצי ב־Supabase SQL Editor את:
   `supabase/migrations/019_add_michal_zundelevich.sql`

בסיום תקין תוצג שורה אחת עבור מיכל זונדלביץ עם:
- `status: active`
- `published: true`
- `online_status: special`
- `service_subregion: טבעון ויקנעם`

המיגרציה ניתנת להרצה חוזרת ואינה דורסת רשומה קיימת. אם כבר קיימת מדריכה בשם זה תחת מזהה מקור אחר, היא נעצרת בלי שינוי.

## מה השתנה

- תמונת המדריכה בכרטיס הוגדלה.
- כל תוכן הכרטיס נשאר בעמודה שמתחילה בקו של שם המדריכה.
- אזור הקבלה הועבר לתחתית הכרטיס.
- כובע אקדמי מחליף את הכיתוב „הכשרה”.
- מקצועות ארוכים נחתכים במילה שלמה ומסתיימים בשלוש נקודות; האורך של הטקסט של שי משמש כמקסימום.
- סינון האזור אוחד לתפריט אחד. בכל אזור־גג מופיעות האפשרות לבחור את כולו ותתי־האזורים שלו.
- קישורי סינון ישנים עם `region` ו־`subregion` ממשיכים לעבוד.
- מיכל זונדלביץ נוספה כמדריכה פעילה ומפורסמת, משויכת לטבעון ויקנעם ומסומנת לקבלת אונליין במקרים מיוחדים.

## תמונה של מיכל

בקובץ Wix קיימת הפניה פנימית לתמונה ולא כתובת תמונה ציבורית. לכן כרגע יוצג עבורה הפיון האוטומטי. ניתן יהיה להוסיף את התמונה אחרי שנבחר את זרימת התמונות החדשה.
