פתיחת עמוד המדריכות לתצוגת בדיקה ציבורית
==========================================

מה העדכון עושה
---------------
- פותח את /educators ואת עמודי הפרופיל לצפייה.
- מפרסם רק את 24 פרופילי המדריכות שיובאו מ-Wix.
- לא מוסיף קישור לעמוד מתוך האתר.
- משאיר את העמוד מחוץ לאינדוקס של מנועי חיפוש.
- מציג הודעה שאזורי השירות עדיין בבדיקה.

סדר ההתקנה
-----------
1. להעלות את שני קובצי הקוד שבתיקיית app אל אותם נתיבים במאגר.
2. להמתין לכך ש-Vercel יסיים את ההעלאה בהצלחה.
3. לפתוח את /educators. בשלב הזה העמוד אמור להיפתח, אך ייתכן שיוצגו 0 מדריכות.
4. לפתוח את Supabase SQL Editor ולהריץ פעם אחת את:
   supabase/migrations/016_publish_educators_preview.sql
5. התוצאה בסיום צריכה להיות public_imported_educators = 24.
6. לרענן את /educators ולבדוק את הכרטיסים, הסינון ועמודי הפרופיל.

חשוב
-----
העמוד אינו מקושר ואינו מיועד כרגע לאינדוקס, אבל הוא ציבורי: מי שמחזיקה בכתובת
יכולה להיכנס ולראות את הפרטים הציבוריים שיובאו מהאתר הישן.

לא להריץ את קובץ ה-SQL לפני שהעלאת הקוד ל-Vercel הסתיימה.

בדיקות שבוצעו
-------------
- TypeScript עבר בהצלחה.
- בניית Production עברה בהצלחה.
- /educators ו-/educators/[id] קיימים בפלט הבנייה.
