עדכון ניהול תמונות בעריכת מודעה — 06.10.2026
================================================

מה נוסף
-------
- הצגת התמונות הקיימות והתמונות החדשות במסך עריכת מודעה.
- בחירת כל תמונה רגילה כתמונה הראשית.
- הסרת תמונות קיימות או חדשות לפני השמירה.
- השינויים בתמונות קיימות מתבצעים רק בלחיצה על „שמירת שינויים”.
- אי אפשר לשמור מודעה קיימת ללא אף תמונה רגילה.
- תמיכה נפרדת גם בהסרת תמונות פגמים.
- הממשק מותאם קודם כול למובייל.

סדר התקנה
----------
1. להריץ תחילה ב־Supabase SQL Editor את:
   supabase/migrations/023_listing_image_editing.sql
2. לוודא שהשאילתה הסתיימה בהצלחה.
3. להעתיק את שלושת קובצי הקוד אל אותם נתיבים בפרויקט ולאשר החלפה:
   components/ListingForm.tsx
   app/listing/[id]/edit/page.tsx
   app/globals.css
4. להעלות ל־GitHub/Vercel בדרך הרגילה.

הערות בטיחות
------------
- הרשאת ה־SQL מאפשרת למשתמשת לעדכן רק רשומות תמונה שבבעלותה.
- לחיצה על „הסרה” אינה מוחקת מיד את התמונה. המחיקה מתבצעת רק בעת שמירת המודעה.
- אם יוצאים מהעמוד בלי לשמור, התמונות הקיימות אינן משתנות.
- אין משתני סביבה חדשים.
